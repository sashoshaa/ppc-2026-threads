## Введение

Последовательная версия алгоритма нужна как базовая реализация и как эталон
для сравнения с многопоточными и гибридными вариантами. В задаче используется
LSD radix sort для `int` с последующим слиянием отсортированных частей.

## Постановка задачи

Требуется отсортировать массив целых чисел по неубыванию.

Для версии SEQ:

- алгоритм выполняется без распараллеливания;
- результат должен быть идентичен эталону (`std::sort`);
- время выполнения `T_seq` используется для расчета ускорения остальных версий.

## Описание алгоритма (SEQ)

Реализация: `seq/src/ops_seq.cpp`, класс `SosninaATestTaskSEQ`.

### Принцип работы

1. Массив делится на две части: `left_part` и `right_part`.
2. Каждая часть сортируется `RadixSortLSD`.
3. Части сливаются функцией `SimpleMerge` в итоговый `data`.
4. Проверяется корректность: `std::ranges::is_sorted(data)`.

### Особенности RadixSortLSD

- Основание: 256 (`kRadixBits = 8`, `kRadixSize = 256`).
- Число проходов: 4 (`kNumPasses` для `int`).
- Для signed-значений используется преобразование `x ^ 0x80000000` до и после
  сортировки.

### Псевдокод

```text
Вход: data
если |data| <= 1: конец
mid <- |data| / 2
left  <- data[0 .. mid)
right <- data[mid .. |data|)
LSD-sort(left)
LSD-sort(right)
merge(left, right) -> data
```

## Оценка сложности

- Время: линейные проходы radix + линейное слияние.
- Память: линейная дополнительная память под буферы и части.
