## Введение

TBB-версия использует модель задач oneTBB для параллельной сортировки частей и
параллельного поуровневого слияния.

## Постановка задачи

Нужно реализовать эффективную многопоточную версию radix+merge с
`tbb::parallel_for`, сохранив корректность результата и стабильность замеров.

## Описание реализации

Реализация: `tbb/src/ops_tbb.cpp`, класс `SosninaATestTaskTBB`.

### Принцип работы

1. Вычисляется число частей `num_parts` (через пороги размера и число потоков).
2. Массив делится на части примерно равного размера.
3. Части сортируются в `tbb::parallel_for`.
4. На каждом уровне merge пары частей также обрабатываются в `tbb::parallel_for`.
5. Используется `tbb::simple_partitioner`.
6. Проверяется корректность через `std::ranges::is_sorted(data)`.

### Псевдокод

```text
разбить data на parts

tbb::parallel_for(i: 0..num_parts):
    LSD-sort(parts[i])

current <- parts
while |current| > 1:
    pair_count <- |current| / 2
    tbb::parallel_for(idx: 0..pair_count):
        next[idx] <- merge(current[2*idx], current[2*idx+1])
    перенос хвоста при нечётном количестве частей
    current <- next
data <- current[0]
```

## Оценка сложности

- По данным: линейные radix-проходы + merge.
- В практике: масштабируемость определяется балансом задач и merge-этапами.
